B. The warm-up is needed because Numba compiles the code during the first run.

C. No. The parallel efficiency decreased as the number of threads increased.
This happens because the CPU has a limited number of physical cores.
D. inside_circle += 1 does not corrupt the count because Numba automatically recognizes it as a reduction operation.
It generates an implicit sum reduction (reduction(+:inside_circle)), where each thread keeps its own count and the counts are combined at the end.

Challange 2:
B. NumPy uses row-major memory, so elements in the same row are next to each other in memory. 
Therefore, writing img[r, c] is cache-friendly. 
Writing by columns is less cache-friendly because memory access jumps between rows, causing more cache misses.
C.The Mandelbrot center is more computationally expensive than the edges. 
If one thread gets the center rows, it needs much more time, while another thread with easier rows finishes early and becomes idle.
Dynamic scheduling solves this by giving threads new rows as soon as they finish their current work, helping balance the workload.
